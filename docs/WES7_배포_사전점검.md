# WES7 제어기 배포 — 사전 점검 및 유의사항

대상: Windows Embedded Standard 7 (버전 6.1, Service Pack 1) 제어기
문서 목적: 설치 전에 준비할 것과, 환경에 따라 문제가 될 수 있는 지점을 미리 공유하기 위함
작성 기준일: 2026-08-20

---

## 요약

챔버 이상 검사 앱은 WES7(Windows 7 SP1)에서 동작하도록 **별도 빌드**로 제공합니다.
Windows 10 용과는 파이썬 버전부터 화면 구성 방식까지 다르며, 산출물 폴더도 분리되어 있습니다.

앱을 구성하는 모든 실행 파일(DLL·PYD 130여 개)에 대해 **Windows 8 이상에서만 존재하는
API를 사용하는지 정적 검사를 마쳤고, 해당 사항이 없음을 확인**했습니다.
다만 아래 **준비 사항**이 충족되지 않으면 기능 일부 또는 앱 전체가 동작하지 않습니다.

## 1. 제어기에 미리 준비해야 할 것

| 항목 | 필요 이유 | 없으면 |
| --- | --- | --- |
| **Visual C++ 2015–2019 재배포 패키지 (x64)** | 파이썬·수치 라이브러리 공통 런타임 | 앱이 시작되지 않음 |
| **.NET Framework 4.6.2 이상** (4.8 권장) | 네이티브 창(WebView2) 구동 | 네이티브 창이 뜨지 않음 |
| **Firefox 115 ESR (64bit)** | 화면 표시(브라우저 모드) | 화면을 볼 수 없음 |
| WebView2 고정버전 런타임 109 | 네이티브 창을 쓸 때만 | **더 이상 배포되지 않음** — 아래 참고 |
| **PowerShell** | 폴더 선택 창 | 폴더 선택 버튼 무반응 (3-②) |
| **디스크 여유 2GB 이상** | 앱 폴더가 1GB를 넘을 수 있음 | 설치·실행 실패 |

> WES7은 필요한 구성요소만 골라 담는 OS입니다. 일반 Windows 7에는 기본 포함되는
> PowerShell, .NET Framework가 이미지 구성에 따라 **빠져 있을 수 있습니다.**
> 설치 전에 아래 두 줄로 확인해 주시면 가장 확실합니다.
>
> ```
> powershell -Command "$PSVersionTable.PSVersion"
> reg query "HKLM\SOFTWARE\Microsoft\NET Framework Setup\NDP\v4\Full" /v Release
> ```
>
> 두 번째 명령의 `Release` 값이 **394802 이상**이면 .NET 4.6.2 이상입니다.

## 2. 확인된 제약 (기술적 배경)

고객사 환경 탓이 아니라 **Windows 7의 지원 종료에서 비롯된 제약**입니다.
참고용으로만 봐주시면 됩니다.

### ① 파이썬 3.8 고정

Python은 3.9부터 Windows 8.1 이상을 요구합니다(Python 공식 문서 명시).
따라서 WES7 배포본은 **Python 3.8**로 빌드하며, 그에 맞춰 모든 라이브러리를
2020~2023년 세대 버전으로 고정했습니다. 기능 차이는 없습니다.

### ② 화면 표시 — WebView2 109 고정

Microsoft는 **Edge 109(2023년 1월)를 끝으로 Windows 7 지원을 종료**했습니다.
WebView2는 Edge 런타임이므로, 현재 배포되는 최신 런타임은 WES7에 설치되지 않습니다.
**확인 결과 이 109 런타임은 현재 구할 수 없습니다.** Microsoft 공식 배포 페이지는
150·151 버전만 제공하고, 예전 버전을 받던 경로도 응답하지 않습니다(404).

그래서 **기본 구성은 브라우저 모드**입니다. 제어기에 **Firefox 115 ESR**(윈도우7에서
동작하는 마지막 버전)을 설치하면 앱이 그 브라우저로 화면을 띄웁니다.
이미 109 런타임을 보관 중인 경우에만 네이티브 창을 쓸 수 있습니다.

WebView2를 준비하기 어려운 현장에서는 **브라우저 모드**로도 제공 가능합니다.
이 경우 제어기에 **Chrome 109** 또는 **Firefox 115 ESR**이 필요합니다.
Internet Explorer로는 화면이 표시되지 않습니다.

### ③ 추론 엔진 — torch 사용

Windows 7에서 동작하는 조합을 찾기 위해 라이브러리별로 검증한 결과입니다.

| 라이브러리 | Windows 7 동작 | 비고 |
| --- | --- | --- |
| onnxruntime 1.15 이상 | ✗ | Windows 8 전용 API 사용 |
| onnxruntime 1.14 이하 | △ | 동작하나 최신 모델 파일 형식을 읽지 못함 |
| **torch 2.3.1** | ✓ | **채택** |
| torch 2.4 이상 | ✗ | Windows 8 전용 API 사용 |

이 때문에 WES7 배포본은 **torch 기반**이며, 모델 파일은 `.onnx`가 아니라
**`.pt` 형식**을 사용합니다. 판정 결과와 정확도는 Windows 10 버전과 동일합니다.
다만 라이브러리 특성상 **앱 폴더 용량이 큽니다(1GB 내외).**

## 3. 환경에 따라 문제가 될 수 있는 지점

### ① 화면이 뜨지 않음 — 발생 가능성 높음

**원인**: WebView2 고정버전 런타임 미배치, 또는 .NET Framework 4.6.2 미만
**증상**: 앱을 실행해도 창이 나타나지 않거나, 창은 뜨지만 내용이 비어 보임
**대응**: 런타임 폴더와 .NET 버전 확인. 그래도 안 되면 브라우저 모드 배포본으로 교체
**확인 방법**: 실행 후 브라우저에서 `http://127.0.0.1:8000` 접속 →
화면이 나오면 앱은 정상이고 **창 표시 방식만** 문제입니다.

### ② 폴더 선택 버튼이 반응하지 않음 — 발생 가능성 있음

**원인**: PowerShell 미포함 (WES7 최소 구성)
**증상**: 검사 폴더·모델 폴더·저장소 위치 선택 버튼을 눌러도 창이 뜨지 않음
**대응**: **경로를 직접 입력하면 모든 기능을 정상 사용**할 수 있습니다.
현재 버전은 이 경우 "PowerShell이 없어 폴더 선택 창을 띄울 수 없습니다"라는
안내를 표시합니다.
**영향 범위**: 편의 기능만 해당. 검사·판정·리포트에는 영향 없음

### ③ RCA(원인 분석) 기능 제한 — 해당 시

**원인**: WES7 배포본은 torch 기반이라 ONNX 형식의 RCA 보조 모델을 사용할 수 없음
**증상**: NG 웨이퍼 상세에서 RCA 생성 시 오류 메시지
**대응**: RCA를 사용하실 경우 사전에 알려주시면 `.pt` 형식으로 준비해 드립니다.
**참고**: 오류 메시지만 표시되고 앱이 종료되지는 않습니다.

### ④ 검사 이력이 재부팅 후 사라짐 — 쓰기 필터 사용 시

**원인**: WES7의 쓰기 필터(EWF / FBWF)가 활성화된 드라이브에 저장
**증상**: 검사 결과·설정이 재부팅하면 초기화됨
**대응**: **설정 > 저장소 위치**에서 필터가 적용되지 않은 드라이브를 지정하십시오.
데이터·보관·로그·리포트 폴더를 각각 별도 경로로 지정할 수 있습니다.

### ⑤ 다른 제어기의 설정을 그대로 옮긴 경우

**증상**: 검사 대상이 0건으로 나오거나 모델을 찾지 못함
**원인**: 이전 장비의 폴더 경로가 설정에 남아 있음
**대응**: **설정 > 폴더 경로 점검**에서 확인 후 [없는 경로 설정 지우기]
앱 폴더 내부 경로는 상대경로로 저장되어 폴더째 이동해도 유지됩니다.

### ⑥ CPU 점유 — 설비 프로그램과 경합

**대응**: **설정 > CPU 사용 제한**에서 연산에 사용하지 않을 코어 수를 지정할 수 있습니다.
'코어 고정' 옵션을 켜면 지정한 코어 밖으로 나가지 않습니다. 설정 후 앱 재시작이 필요합니다.

## 4. 검증되지 않은 항목

정직하게 말씀드립니다. 아래는 **실제 제어기에서만 확인 가능**합니다.

| 항목 | 현재 상태 |
| --- | --- |
| 라이브러리 로딩 | **정적 검증 완료** — 실행 파일 130여 개 전수 검사 |
| 실행 중 동작 | **미검증** — 로딩 이후의 동작은 실기 확인 필요 |
| WebView2 109 창 표시 | **미검증** — 런타임 배치 후 확인 필요 |
| 제어기 성능에서의 처리 속도 | **미검증** — 데이터 양에 따라 다름 |

정적 검증은 "프로그램이 시작될 수 있는가"까지를 보장하며,
그 이후 동작까지 보장하지는 않습니다.

## 5. 권장 검증 절차 (약 30분)

무인 라인에 바로 투입하기 전에 아래 순서를 권장드립니다.

1. **전제조건 확인** — 1장의 두 명령으로 PowerShell·.NET 확인
2. **앱 실행** — 콘솔 창이 함께 뜹니다(정상). 마지막 메시지 확인
   - `[engine] 모델 로드(torch)` 가 표시되면 정상
3. **소량 검사** — 웨이퍼 10~20장으로 검사 실행, 판정 결과 확인
4. **리포트 생성** — 한글이 정상 표시되는지 확인
5. **재부팅 후 재실행** — 검사 이력이 유지되는지 확인 (쓰기 필터 점검)

문제가 발생하면 앱 폴더에 아래 파일이 자동 생성됩니다.
**이 파일들을 보내주시면 원인 파악이 가능합니다.**

- `앱_시작기록.txt` — 어느 단계까지 진행했는지
- `앱_시작오류.txt` — 오류 내용
- `앱_크래시.txt` — 라이브러리 수준 오류
- `로그\app_<날짜>.log` — 실행 로그

## 6. 운영상 유의사항

- 이 배포본이 사용하는 구성요소들은 **보안 업데이트가 종료된 버전**입니다.
  Windows 7 자체의 지원 종료(2020년 1월)에 따른 것으로,
  **폐쇄망 환경 전용**으로 사용하시기를 권장합니다.
- 앱은 외부 통신을 하지 않으며, `127.0.0.1`(로컬)에서만 동작합니다.
- 향후 제어기를 Windows 10 이상으로 교체하시면 표준 배포본을 사용할 수 있습니다.
  이 경우 GPU 가속을 포함한 최신 구성이 적용됩니다.
