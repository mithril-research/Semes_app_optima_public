# RCA 강화 — 현황 파악 결과와 작업 계획

| 항목 | 내용 |
|---|---|
| 브랜치 | `feature/rca-v3` (기준선 태그 `v1.0-win7`) |
| 작성일 | 2026-08-30 |

---

## 1. 착수 전 확인한 사실 (중요)

### 1-1. 반사실 검증은 이미 구현돼 있다

새로 만들 필요가 없었다. 기존 모듈을 확인한 결과:

| 모듈 | 줄 수 | 역할 |
|---|---|---|
| `src/h_counterfactual_rca.py` | 1,304 | **반사실 검증** — H 제어변수를 개입 입력으로 보고 델타를 스윕하며 PT 모델을 재실행, 복원오차 감소량(`pt_improvement_pct`)으로 후보 순위 산출 |
| `src/rca_slope_valve.py` | 3,101 | 누적 복원오차 기울기로 focus 스텝 선정 → 그 스텝에 열린 밸브와 관련 센서 목록 |
| `src/rca_v2.py` | 1,850 | 규칙 기반 오버레이 |

앱은 `/api/rca/{date}/{wid}` 에서 **slope-valve + h-counterfactual 을 둘 다 실행**하고 결과를
`result.json` 에 캐시한다. 즉 **계산층은 상당 부분 완성돼 있다.**

### 1-2. 진짜 문제는 '표현'과 '사전(辭典)'이다

| 층 | 상태 | 남은 일 |
|---|---|---|
| 계산 | 반사실·기울기·밸브 연관 **구현됨** | 순서(onset) 축 추가 |
| 표현 | **마크다운 리포트 원문을 그대로 화면에 출력** | 5줄 결론 카드로 재구성 ★ |
| 사전 | **없음** | 스텝 번호→공정명, IO 태그→설비명 (고객사) |

### 1-3. 이 개발 환경에서는 RCA 를 실행할 수 없다

- 검사 폴더에 원본 `.log` **0개**
- 보관 npz 는 `actual/expected/z/step/meta` 만 저장 — **IO 가 없음**
- RCA 는 밸브(IO) 상태가 필수라 아카이브만으로 재현 불가

→ **결론: 실기 데이터 없이는 출력 확인이 불가능하다.** 원본 로그 확보가 선행 과제.

### 1-4. 실측 데이터에서 드러난 설계상 함의

보관 웨이퍼 `RLWAFER2`(점수 19.19) 분석 결과:

- 스텝 1 시작 시점에 **7개 센서가 동시 이탈** — 전파 시차 없음
- 따라서 "먼저 움직인 센서" 근거가 **이 사례에서는 무력**
- → 반사실 검증이 원인 판별의 **유일한 축**이 되는 실제 사례가 존재

이는 순서(onset) 축을 추가하되 **그것에만 의존하면 안 된다**는 근거다.

## 2. 작업 계획

### 2-1. 목표

복원 모델의 출력("무엇이 · 언제 · 어느 방향으로 평소와 달랐나")을
공정 엔지니어가 읽는 형태("원인 후보 → 근거 → 점검 대상")로 전환한다.

### 2-2. 단계

| 단계 | 내용 | 선행 조건 | 산출물 |
|---|---|---|---|
| **A** | 결론 카드 UI — 기존 RCA 결과(`result.json`)를 5줄로 재구성 | 없음 | 화면 + 리포트 1페이지 |
| **B** | 이탈 순서(onset) 축 추가 — 연속 N행 이상 `\|z\|≥1` 최초 시점 | 없음 | 근거 1 |
| **C** | 반사실 결과를 카드 ③에 연결 (이미 계산됨 — 표시만) | 없음 | 근거 2 |
| **D** | 사전 적용 — 스텝·태그 CSV 를 읽어 번역 | **고객사 표** | 카드 ①④ |
| **E** | 점검 규칙표 — 조건×방향 → 점검 후보 | **고객사 협업** | 근거 3 |
| **F** | 사례 라이브러리 — 시그니처 유사도 + 조치 기록 | 운영 기간 | 근거 4 |

A~C 는 **고객사 입력 없이** 가능하다. D 부터는 고객사 협업이 필요하다.

### 2-3. 확신도 표기 규칙

근거 4축(순서·반사실·규칙·사례) 중 몇 개가 같은 센서를 가리키는지로 표기한다.

- 3~4/4 → **원인 후보**
- 2/4 → 가능성
- 1/4 이하 또는 축 간 불일치 → **불확실** — 갈린 가설을 모두 제시

`RLWAFER2` 처럼 동시 이탈이면 순서 축이 빠지므로 자동으로 확신도가 낮아진다.

| 과제 | 비고 |
|---|---|

| 스텝 사전 · 태그 사전 양식 전달 | D 단계 선행 — 빈 CSV 서식 제공 예정 |
