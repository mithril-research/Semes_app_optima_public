# 레시피별 스텝 소요시간·센서 피크 추이

오버뷰의 산점도를 연 뒤 센서 추이 맨 아래에서 ‘스텝 시간·피크 조회’를 누른다. 산점도 대상 웨이퍼 중 선택한 레시피·챔버의 자료를 종료시각순으로 표시한다. 최초 조회는 버튼을 눌렀을 때만 수행하고 동일 산점도 데이터에서는 결과를 재사용한다.

- 레시피를 선택하면 세로 막대 하나에 스텝별 평균 소요시간을 번호순으로 누적한다. 챔버 필터도 적용한다.
- 각 스텝은 유효한 시간 자료만 평균내며, 누락을 0초로 넣지 않는다. 구간과 범례에 평균 및 유효/전체 웨이퍼 수를 표시한다. 평균 시간 합계는 스텝별 평균의 합이므로 결측이 있으면 웨이퍼 총시간 평균과 다를 수 있다.
- 스텝 구간 또는 범례를 클릭하면 해당 레시피·챔버에 속한 웨이퍼들의 센서 피크 추이를 센서별로 표시한다. 시간 자료가 없는 스텝도 피크 자료가 있으면 범례로 선택할 수 있다.
- 피크는 종료시각순 전체 웨이퍼를 점으로 표시하며 가로 스크롤로 조회한다. 체크박스로 원하는 센서만 표시할 수 있고 선택은 스텝을 바꿔도 유지한다. 챔버별 색상과 모양을 구분하고, 점에 마우스를 올리면 웨이퍼·시각·스텝·값을 표시한다. 센서별 세로축은 전체 대상 웨이퍼 기준으로 유지한다.
- Enter/Space로 스텝을 선택할 수 있다. 레시피·챔버를 바꾸면 피크 선택을 초기화한다.

## 계산 기준

사용자 요청에 따라 우선 Time을 시간 기준으로 사용한다. 숫자 Time은 초, HH:MM:SS(.소수)는 시각으로 해석한다. 한 스텝의 연속 구간에서 다음 스텝 첫 Time − 현재 스텝 첫 Time을 계산하고, 같은 스텝이 반복되면 각 구간의 시간을 합산한다. 마지막 스텝은 마지막 기록까지만 계산한다. 한 줄 스텝도 다음 스텝 시작 시간이 있으면 계산한다. 시각만 있는 자료의 자정 통과는 보정한다. 다른 역행, 결측, 다음 종료 경계도 없는 마지막 한 점 구간은 계산 불가다. 이 방식은 관측된 기록의 시간 차이이며 장비의 별도 남은 시간 카운터 계산은 아니다. 스텝 0은 제외한다.

시간 계산이 불가한 웨이퍼·스텝은 평균에서 제외하며 유효 표본 수로 확인할 수 있다. 유효 시간이 없는 스텝은 범례에 시간 없음으로 표시한다. 센서 피크는 시간 자료가 없어도 보관 센서 통계가 있으면 표시한다. 센서 피크는 소요시간과 별개인 아래 그래프에 표시한다.

## 보관·이전 자료·HTML

새 검사에서는 원본 프레임의 Time과 ProcessStep에서 계산한 작은 시간 요약을 NPZ 메타데이터에 저장한다. 기존 NPZ에 요약이 없으면 등록 경로의 원본 로그/CSV를 찾아 계산한다. 원본도 없으면 재검사 또는 원본 복원이 필요하다고 표시한다. 기존 추론 점수는 변경하지 않는다.

센서 피크는 보관된 센서값의 스텝별 max로 계산하므로 보관 정밀도의 영향을 받을 수 있다. ‘센서값·센서 차이 추이’ 내보내기 옵션에 시간 요약과 피크 자료도 포함하며 오프라인 HTML에서 조회할 수 있다. 피크는 선택 통계와 별개로 이 기능에 필요하므로 max 통계를 체크하지 않아도 피크 자료는 포함한다.

## 검증

숫자/시각/소수초, 자정 통과, 반복 스텝, 스텝 0 제외, 누락/역행/한 점, 보관 요약 우선 및 원본 부재를 자동 시험한다. Firefox 115의 오프라인 HTML에서 70매×2스텝 누적 막대와 피크 점, 챔버 필터, 하단 위치를 확인했다. 실제 설비 로그의 Time 의미·단위는 현장 확인이 필요하다.

시간 요약 버전 2부터 스텝 전환 경계를 사용한다. 기존 요약이나 계산 실패 요약은 원본 파일로 재계산을 시도한다. 원본이 없으면 기존 요약임을 반환하고, 시간 자료가 없으면 원본 복원 필요 안내를 표시한다. 화면 조회 버튼은 계산 불가 자료를 다시 요청한다.

## 배포 모듈 및 파싱 캐시 수정

시간 계산 구현을 기존 src/data.py로 이동했다. 앱의 파일 로드와 기존 원본 재계산은 별도 src/step_timing.py 설치 없이 동작한다. 해당 파일은 이전 코드용 호환 import만 남긴다.

파싱 캐시가 Time 문자열을 숫자로 변환하며 NaN으로 저장하던 경로를 수정했다. 원본 프레임에서 시간 요약을 계산해 캐시에 별도 저장하고 재사용한다. 캐시 버전을 변경했으므로 구형 캐시는 원본에서 한 번 다시 생성한다. 보관된 오래된 검사 결과는 원본이 있어야 새로운 방식으로 복원할 수 있다.

## 레시피 막대 UI 검증
Firefox 115 오프라인 HTML에서 70매×2스텝을 레시피 막대 하나로 집계하고, 서로 다른 웨이퍼 시간의 평균값을 확인한다. 스텝 클릭 후 센서별 웨이퍼 피크, 전체 70매 표시·가로 스크롤·센서 선택, 챔버 필터, Enter 선택을 확인한다. 계산식과 보관 형식은 변경하지 않는다. 내보낸 HTML에도 동일 UI가 적용되며 새로 생성해야 한다.

막대 내부는 초 수치를 빼고 스텝 이름을 18px로 표시한다. 차트 높이를 스텝 수에 맞춰 늘리며, 비율상 작은 구간은 막대 밖 연결선과 스텝 이름으로 표시한다. 평균시간 수치는 툴팁과 범례에서 확인한다.

## 스텝 라벨 및 시간축 개선
스텝 라벨은 막대 오른쪽에 색상 표시가 있는 흰색 배지로 배치한다. 아래부터 스텝 순서대로 간격을 확보하고 연결선으로 해당 구간을 연결한다. 충분히 큰 구간 안에는 스텝 이름도 표시한다.
센서 피크 그래프 X축은 종료시각의 실제 시간 간격으로 배치하며 날짜·시분초 눈금을 표시한다. 같은 시각은 같은 X좌표에 위치한다. 종료시각 누락은 제외하고 건수를 안내한다. 전체 웨이퍼 가로 스크롤과 센서 선택을 유지한다.

## 독립 조회
레시피별 시간·피크 패널은 전체 산점도를 그릴 때 즉시 생성한다. 센서값/센서 차이 조회 완료 여부와 무관하게 별도 버튼으로 조회한다. 센서값 조회가 실패해도 레시피 조회는 가능하며, 센서값 패널이 나중에 생성되어도 레시피 패널은 맨 아래에 유지한다. 두 기능은 각자 API와 캐시를 사용하고 산점도 재조회 시 함께 취소된다.

## 전체 센서 선택
개별 센서값 추이와 레시피별 센서 피크 추이에 각각 전체 센서 선택 버튼을 제공한다. 현재 조회 가능한 센서를 모두 체크하고 그래프를 갱신하며 선택 상태를 저장한다. 센서 자료가 없으면 버튼을 비활성화한다. 오프라인 HTML에도 동일하게 적용된다.

## 고정 Y축 및 센서 스크롤 동기화
레시피별 피크 그래프의 Y축 눈금은 스크롤 영역 밖에 고정한다. 한 센서 그래프를 가로 스크롤하면 같은 레시피 패널의 다른 센서 그래프도 같은 위치로 이동한다. 센서 선택을 바꿔도 스크롤 위치를 유지한다.

## 피크 이동평균선
선택 스텝의 센서별 피크에 이동평균선을 표시한다. 기본은 조회기간 시작부터 현재 웨이퍼까지의 누적 평균이며 이전 N분으로 변경할 수 있다. 같은 챔버·레시피끼리 계산하고 랏 첫장 및 결측은 제외한다. 검정선을 점 위에 표시하고 챔버별 선 모양을 구분한다. 표시 여부·시간 설정을 유지하며 오프라인 HTML에서도 계산한다.

## 센서 선택 해제 및 개별 센서값 표시
개별 센서값 추이는 챔버별 고유색을 사용하며 평균은 원, min은 사각형, max는 삼각형, 표준편차는 마름모로 표시한다. 통계 선택과 범례도 같은 모양으로 안내한다. 기존 이동평균선 색상·선 모양은 유지한다. 개별 센서값 및 레시피 피크 센서 선택 영역에 전체 선택 해제 버튼을 추가한다.

## 챔버 공통 선택과 차이 추이
센서값 차이 추이도 챔버별 색상, 통계별 모양을 사용한다. 산점도 상단의 모든 그래프 표시 챔버 선택은 전체·온도·압력 산점도, 센서값·차이 추이, 레시피 추이에 공통 적용한다. 전체 선택/해제가 가능하며 필터 후 대상 웨이퍼로 그래프와 이동평균을 계산한다. 레시피 이동평균은 연회색, 센서값/차이 이동평균은 기존 색상을 연하게 표시한다.

## 수동 조회 전환 및 레시피 이동평균 제거
레시피 피크 이동평균선과 설정 UI를 제거한다. 센서값 차이, 개별 센서값, 레시피 추이는 각각 버튼을 눌렀을 때만 조회·계산한다. 이전에 열었던 레시피도 산점도 재생성 시 자동 조회하지 않는다. 차이/개별 센서값의 보관 통계 조회 API와 캐시는 공유하지만 다른 패널을 자동 생성하거나 그리지 않는다. 실패 시 버튼으로 재시도한다.

## 전체 챔버 막대 분리
전체 챔버 선택 시 레시피에 해당하는 챔버별로 스텝 평균시간 누적 막대를 가로로 배치한다. 모든 막대의 시간축 최대값을 통일하고 가로 스크롤을 지원한다. 막대/범례의 스텝 클릭 시 해당 챔버의 웨이퍼 센서 피크만 표시한다. 단일 챔버 선택 시 해당 막대 하나를 표시한다.

## 직접 스텝 구간
센서값 차이와 개별 센서값 추이에서 시작·끝 스텝을 입력하고 스텝 구간 적용을 누른다. 양끝을 포함하며 스텝 0과 자료 없는 스텝은 제외한다. 평균은 스텝별 동일 가중치, min/max는 구간 극값, 표준편차는 스텝 평균 차이를 포함한 합동 분산으로 계산한다. 내보낸 HTML에 평균이 없으면 여러 스텝의 표준편차를 정확히 합칠 수 없어 해당 값은 표시하지 않는다. 레시피 및 수동 조회 제목 크기는 14px로 통일한다.

## 영역별 챔버·가로축 선택
공통 모든 그래프 표시 챔버를 제거하고 센서값 차이와 개별 센서값 영역에 독립적인 챔버 체크박스 및 전체 선택/해제를 둔다. 각 영역에서 가로축 시간 간격(10분, 30분, 1시간, 6시간, 12시간, 1일)을 지정할 수 있다. 기존 시작/종료시각 입력으로 표시 범위도 제한한다. 두 영역의 선택 상태는 각각 저장되며 전체 산점도나 레시피 추이에 영향을 주지 않는다.

## 레시피 피크 시간축과 한눈에 보기
레시피 센서 피크에도 10분·30분·1시간·6시간·12시간·1일 가로축 시간 간격을 제공한다. 기본은 30분이다. 한눈에 보기는 전체 종료시각 범위를 화면 너비에 맞추고 시간 간격 보기 버튼으로 복귀한다. Y축 고정, 센서 간 스크롤 동기화와 센서 선택을 유지한다.

## 웨이퍼별 스텝 소요시간 막대
레시피 센서 피크 그래프의 각 웨이퍼 위치에 선택 스텝 소요시간을 반투명 회색 막대로 표시한다. 막대는 피크 점 뒤에 그리며 왼쪽 축은 센서값, 오른쪽 고정 축은 초 단위 시간이다. 막대/피크에 마우스를 올리면 시간이 표시된다. 시간 자료가 없으면 막대를 생략하고 피크 툴팁에 계산 불가를 표시한다. 시간축/한눈에 보기/스크롤 동기화를 유지한다.

## 배치 및 집계 기준 명시
개별 센서값 추이를 센서값 차이 추이 앞에 배치한다. 스텝 직접 지정은 공정 스텝 구간 선택 옆에 배치하며 좁은 화면에서 줄바꿈한다. 누적 막대는 선택 레시피 안에서 해당 챔버 웨이퍼만 모아 스텝별 평균을 계산한다. 카드에 레시피·챔버·표본 수를 명시한다. 공통 Y축 최대값은 비교용 축 범위이며 평균을 합치는 값이 아니다.

## 레시피 다중 챔버·기간 필터
레시피 추이에 챔버 체크박스와 전체 선택/해제를 제공한다. 웨이퍼 종료시각 기준 시작·종료 기간을 적용하거나 전체 기간으로 복원할 수 있다. 조회된 산점도 자료 안에서 필터링하며 양끝을 포함한다. 필터 변경은 챔버별 평균 막대와 센서 피크·소요시간 막대에 함께 반영된다. 역전 기간은 적용하지 않는다.

## 레시피 센서 Y축 설정
각 센서 피크 그래프에 왼쪽 Y축 최소·최대·눈금 간격과 적용/자동 버튼을 제공한다. 설정은 센서별로 유지한다. 범위 밖 점은 그래프 영역에서 잘라 표시한다. 오른쪽 소요시간 축은 자동 범위를 유지한다. 최소≥최대 또는 0 이하 눈금은 거부하고 과도한 눈금은 200개로 제한한다.

## 전체 산점도 시간 간격 동기화
추이의 기본 시간 간격은 전체 산점도의 설정을 따른다. 전체 산점도 시간 간격을 변경하면 센서값/차이/레시피 피크에 같은 설정을 적용하고 열린 패널을 캐시로 다시 표시한다. 조회하지 않은 패널은 버튼 상태를 유지한다. 이후 각 추이에서 별도 시간 간격을 지정할 수 있으며, 전체 산점도를 다시 변경하면 다시 동기화한다. 레시피 한눈에 보기는 동기화 시 시간 간격 보기로 전환한다.

## 추이 열기/닫기
개별 센서값, 센서값 차이, 레시피 추이 및 온도/압력 센서 이상점수 제목에 열기/닫기 버튼을 둔다. 닫기는 표시만 숨기므로 조회 결과와 선택 상태를 유지하고, 다시 열어도 추가 조회하지 않는다. 영역별 접힘 상태를 유지한다. 수동 조회 전에는 버튼 영역을 접고 펼칠 수 있다.

## 스텝 소요시간–센서 피크 관계
레시피 조회 후 스텝과 센서를 선택하고 관계 산점도 생성을 누른다. 선택 레시피·기간·다중 챔버의 웨이퍼를 소요시간(초) X축과 센서 피크 Y축으로 비교한다. 점 모양은 모든 챔버에서 원으로 통일하고 챔버별 색상으로 구분하며 유효 표본/누락 수를 표시한다. 점 툴팁에서 값과 웨이퍼를 확인하고 클릭 또는 Enter로 상세에 진입한다. 기존 보관 시간·피크를 사용하므로 추가 API 조회가 없다. HTML 내보내기에도 포함된다.

관계 산점도는 센서별 Y축 최소·최대와 범위 적용/자동 복원을 지원한다. 빈 입력은 자동 범위이며 최소≥최대 입력은 거부한다. 범위 밖 점은 그래프 영역에서 잘라 표시한다.

관계 분석의 스텝 선택 왼쪽에 레시피 선택을 제공한다. 상단 레시피와 연동되어 변경 시 해당 레시피의 챔버 평균·스텝·센서 목록을 갱신하며, 기존 관계 그래프는 지운 후 생성 버튼으로 다시 표시한다. 챔버·기간 조건은 유지한다.

조회 전 패널의 닫기 버튼이 조회를 실행하던 오류를 수정했다. 첫 번째 button을 선택하던 코드를 조회 전용 .trend-load 선택으로 변경하여 토글 이벤트 덮어쓰기를 방지한다.
