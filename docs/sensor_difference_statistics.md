# 센서값 차이 추이 — 통계 및 구간 선택

기존 압력 3쌍·온도 3쌍의 실측 A−B 추이에 다음을 추가했다.

- 스텝 선택: 기존 1~5, 6~10 등의 구간 또는 개별 공정 스텝을 하나 선택한다. 실제 존재하는 양수 스텝만 표시한다.
- 평균(파랑) / min(초록) / max(빨강) / 표준편차(보라)를 모든 그래프에서 기본으로 동시에 표시한다. 체크박스로 원하는 통계만 선택할 수 있다. 처음에는 네 항목 모두 선택되며 전체 해제 시 그래프 없이 선택 안내만 표시한다. 선택 상태는 스텝·시간 구간·스케일 변경과 그래프 재표시 시 유지된다. 웨이퍼 종료시각 순 점으로 표시하며 데이터 연결선은 그리지 않는다.
- 각 그래프의 Y축 최소·최대·눈금 간격을 입력하고 스케일 적용한다. 빈 항목은 자동이다. 자동 버튼은 해당 그래프 설정을 해제한다. 축 밖 점은 그래프 내부로 잘라 표시하며 계산값은 변경하지 않는다. 200개를 넘는 눈금 등 부적절한 축 설정은 안내한다.
- 각 점의 마우스 설명에는 4개 통계를 모두 표시한다.
- 표시 구간: 웨이퍼 종료시각의 시작·끝을 지정하고 '구간 적용'한다. 양 끝을 포함하며 빈 입력은 해당 방향 제한 없음이다. 오버뷰 산점도에서 조회한 웨이퍼 범위 안에서만 좁힌다. '전체 구간'으로 해제한다.
- 시간 구간을 좁히면 차이 그래프의 가로축을 해당 웨이퍼 범위로 다시 맞춘다. 기존 전체·센서 이상점수 산점도의 조회 조건은 바꾸지 않는다.
- 그래프 상단에 표시 중인 웨이퍼 평균값들의 평균/min/max/표준편차를 별도로 표시한다. 표본이 없으면 통계를 만들지 않으며 한 개면 표준편차는 0이다.
- 축 스케일·스텝·적용 시간 구간은 그래프 재표시 시 유지하며 캐시된 자료로 계산하므로 선택 변경마다 서버 재조회하지 않는다.
- HTML 내보내기에도 동일하게 포함된다.

## 통계 정의

개별 스텝은 해당 웨이퍼의 그 공정 스텝에서 유효한 A−B 표본으로 계산한다. 보간된 점은 원래 간격으로 환원한다. 스텝 0과 비유한 표본은 제외한다.

스텝 구간의 평균은 기존 방식처럼 유효 스텝별 평균을 동일 가중치로 평균한다. min/max는 해당 유효 스텝들의 실측 차이 최솟값/최댓값이다. 표준편차는 각 스텝 내부 분산과 스텝 평균 간 차이를 함께 반영한다:

`variance = mean_over_steps(step_std² + (step_mean − block_mean)²)`

`std = sqrt(variance)`

모든 표준편차는 모집단 기준(ddof=0)이다. 스텝 길이가 다르더라도 각 스텝의 총 가중치는 같으므로 단순히 모든 측정점을 합친 표준편차와 다를 수 있다. 누락된 센서/스텝은 0으로 채우지 않는다.

그래프 위 요약은 스텝 평균값의 웨이퍼 간 분포이다. 점의 툴팁 통계는 한 웨이퍼 내부의 선택 공정 스텝 분포이므로 두 통계의 대상을 구분한다.

## 개별 센서값 추이 (2026-09-28)

센서 차이 그래프 아래에 별도 영역을 제공한다. 보관 자료의 온도·압력 센서 중 원하는 센서를 체크하면 센서마다 그래프가 순서대로 나타난다. 처음에는 센서가 선택되지 않는다. 평균/min/max/표준편차는 모두 선택된 상태로 시작하며 원하는 통계만 남길 수 있다.

각 점은 해당 웨이퍼의 선택 스텝에서 해당 센서 실측값을 집계한 결과이다. 이상점수 또는 센서 간 차이를 표시하는 그래프가 아니다. 스텝 0, 비유한 값, 누락 자료는 제외한다. 기존 차이 그래프와 같은 스텝 동일 가중 평균·분산 규칙을 사용한다. 개별 스텝/스텝 구간, 시작·종료시각, 센서별 Y축 최소·최대·눈금 간격을 지정할 수 있다.

센서와 통계 선택, 시간 범위, 센서 이름별 축 설정은 화면 재표시 시 유지한다. 차이 그래프 설정과는 독립적이다. 이미 로드한 보관 통계를 공유하므로 체크할 때마다 추가 서버 요청을 하지 않는다. HTML 내보내기에도 센서 통계가 포함된다. 과거 내보낸 HTML에는 자료가 없으므로 새로 내보내야 한다.

추가 검증: 실측값의 스텝별 4개 통계·누락·스텝 0 제외, Firefox 115 내보낸 HTML의 기본 무선택·센서 2개 선택 시 그래프 2개 및 통계 곡선 8개·개별 스텝 전환·선택 유지.

## 점 표시·이동평균·선택 항목 자동 축 (2026-09-28)

센서 차이와 개별 센서 추이는 데이터 연결선 없이 채운 점으로 표시한다. 선택한 각 통계의 이동평균은 원자료와 다른 고정 색상의 이동평균선으로 표시한다. 이동평균 표시를 켜고 끌 수 있으며 기본 기준은 조회기간 전체로, 조회 시작부터 현재 시점까지의 누적 이동평균이다. 시간 직접 지정을 선택하면 이전 N분 기준도 사용할 수 있다. 1~525600분 정수로 변경할 수 있다.

이동평균은 현재 표시 구간에 포함된 웨이퍼 중 같은 챔버·레시피의 자료로 계산한다. 기본 모드는 조회 시작부터 현재 시각까지, 시간 직접 지정은 [현재 시각−설정 시간, 현재 시각]을 사용한다. 현재 점과 시간 경계를 포함하고 유효한 웨이퍼마다 동일한 비중을 둔다. 원본 측정점 수로 가중하지 않는다. 조회 구간 앞의 자료나 미래 자료는 넣지 않는다. 표본 하나면 그 값이며 표본 수를 툴팁에 표시한다. 점수 미존재와 챔버·레시피 미상에는 이동평균 점을 만들지 않는다. 이동평균은 ‘랏 첫장 포함’ 체크 상태와 관계없이 랏 첫장을 항상 제외한다. 첫장 위치에는 이동평균 점을 표시하지 않으며 나머지 유효 웨이퍼만으로 계산한다.

자동 Y축은 표시 중인 통계와 시간 구간의 값만 사용하며 0을 강제로 포함하지 않는다. 통계 체크를 바꾸면 기존 수동 축 설정을 해제하고 자동으로 맞춘다. 이후 사용자가 수동 축을 다시 지정할 수 있다. 원자료와 이동평균이 함께 표시되므로 이동평균은 같은 선택값의 범위 내에 놓인다.

검증: 시간 창 경계, 챔버·레시피 분리, 누락과 첫장 제외, 조회 범위 한정 자동 시험. Firefox 115 내보낸 HTML에서 연결선 제거, 이동평균 표시/해제, 시간 창 입력, 개별 센서, 0을 강제하지 않는 자동 축을 확인한다.

### 여러 챔버 구분
센서 차이 및 개별 센서값 추이에서 통계 항목 색상은 유지하고 챔버별 고정 점 모양을 사용한다. DSV1 원, DSV2 사각형, DSV3 삼각형, DSV4 마름모, DSV5 오각형, DSV6 육각형이다. 각 그래프에 챔버 범례를 표시하고 툴팁에도 챔버 이름을 포함한다. 이동평균은 별도 색상의 선으로 표시하며 챔버별 고정 선 패턴과 범례로 구분한다. 챔버·레시피가 다른 데이터는 서로 연결하지 않는다. 원자료는 기존 챔버 모양의 점을 유지한다. 미상 및 기타 챔버는 원 모양이며 범례와 툴팁에 이름을 표시한다. 내보낸 HTML에도 동일하게 적용된다.

온도·압력 센서별 이상점수 산점도에도 동일한 챔버별 고정 모양과 범례, 툴팁의 챔버 이름을 적용한다. 센서 고유 색상은 유지한다. Y축 상한 초과점도 채운 모양으로 표시하고 진한 테두리 및 툴팁으로 상한 초과를 알린다.

원자료 아이콘 크기를 3.5에서 5.5로 확대하고 흰색 테두리를 추가했다. 원자료 아이콘을 먼저 그린 뒤 이동평균선을 위에 표시한다. 이동평균선은 평균 주황(#c05600), min 청록(#0e7490), max 갈색(#854d0e), 표준편차 짙은 회색(#111827)으로 원자료와 구분한다. 선 두께는 2.6이며 범례에 점과 이동평균선의 색상을 각각 표시한다.
