# HTML 내보내기 기능 선택

설정 → 데모용 HTML 내보내기에서 포함할 기능을 체크한 후 HTML 내보내기를 누른다.

| 구분 | 포함 내용 |
|---|---|
| 항상 포함 | 오버뷰, 전체 웨이퍼 산점도, 기본 점수 산포추세, 이력 검색을 위한 검사 요약 |
| 센서별 이상점수·스텝/센서 선택 계산 | 센서 점수, 웨이퍼별 스텝×센서 행렬, 정상 학습 기준 자료 |
| 센서값·센서 차이 추이 | 모든 대상 웨이퍼의 공정 스텝별 실측 통계, 평균/min/max/표준편차 및 이동평균 표시 자료 |
| 이상분석 상세·원본 파형·오버레이 | 이상분석 화면과 최근 50매의 보관 상세 자료. 필요한 센서/스텝 점수 자료도 자동 포함 |

기존 동작과 호환되도록 최초에는 전체 선택이다. ‘기본 화면만’은 세 옵션을 모두 해제하며, ‘전체 포함’은 모두 선택한다. 이상분석 상세를 선택한 동안 점수 계산 옵션은 체크된 상태로 고정된다.

제외 기능은 서버에서 자료 생성/아카이브 조회를 건너뛰고 HTML 직렬화에서도 제외한다. 내보낸 HTML에서는 해당 그래프 및 이상분석 탭을 숨긴다. 제외된 상세를 산점도에서 열려 하면 포함 옵션으로 다시 내보내도록 안내한다. 기본 화면만 내보내면 원본 파형, 학습 행렬, 센서 통계를 넣지 않는다. 요약 이력 자체가 많다면 파일이 여전히 클 수 있고, 감소 비율은 실제 데이터에 따라 달라진다.

단일 HTML 및 기존 최근 7일 수동 조회, 직접 기간 선택 방식은 유지한다. 전체 선택 API 호출 및 이전 호출(새 인자 생략)은 기존 기능을 모두 포함한다. API: GET /api/export-html?include_scores=false&include_trends=false&include_detail=false

검증: 8가지 옵션 조합별 데이터 포함/제외, 기본 내보내기의 아카이브/점수 계산 미호출, UI 스크립트·내보낸 HTML 문법. Firefox 115에서 기본 화면, 점수 없이 센서값 추이만 포함, 상세 탭 제외 및 체크 의존성을 확인했다. 1GB 실제 파일의 감소량은 측정하지 않았다.

## 센서 추이 개별 스텝 및 통계 선택 (2026-09-29 수정)

HTML에서 스텝 1, 스텝 2 등 개별 스텝을 선택할 수 있다. 1~5, 6~10 같은 묶음 구간만 제거한다. 스텝 0은 제외하며 데이터에 존재하는 스텝을 목록에 표시한다. 앱 자체의 묶음 구간 선택은 유지한다.

내보낼 때 평균·min·max·표준편차를 복수 선택한다. 각 웨이퍼·센서·개별 스텝의 선택 통계만 저장하고, 미선택 통계·count·중복 묶음 평균 배열은 제외한다. 개별 스텝의 표준편차는 해당 스텝 실측값의 모집단 표준편차(ddof=0)다. 센서값과 센서 차이 추이에 동일하게 적용하며 스텝 변경 시 그래프와 이동평균을 다시 계산한다.

직전 전체 스텝 집계 방식보다 파일은 커질 수 있으나, 개별 스텝 선택에 필요한 통계만 포함한다. 새 HTML을 생성해야 반영된다.
