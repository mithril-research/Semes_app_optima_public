챔버 이상 검사 시스템 - 설치 설명서
대상: Windows 7 (Professional K / Ultimate, 6.1.7601 SP1, 64비트)

===============================================================
  준비하기 전에
===============================================================

이 폴더의 파일들은 번호 순서대로 실행하면 됩니다.

    1.설치설명서.txt              지금 보고 계신 파일
    2.필수패키지 다운로드.bat     인터넷 되는 PC 에서 실행
    3.앱빌드.bat                  인터넷 되는 PC 에서 실행
    4.제어기 설치.bat             제어기에서 실행 (관리자 권한)
    5.모델 변환.bat               모델을 준비할 때 한 번만

메일로 받으셨다면 파일 이름이 "...bat.txt" 로 되어 있습니다.
압축을 푼 폴더에서 명령 프롬프트를 열고 아래 두 줄을 실행하면 원래 이름으로 돌아갑니다.

    ren *.bat.txt *.bat
    ren src\app\*.bat.txt *.bat


===============================================================
  0. 필요한 것
===============================================================

[ 빌드용 PC ]  인터넷이 되는 아무 PC (윈도우 10/11 이어도 됩니다)
   - Python 3.8 (64비트) 가 설치되어 있어야 합니다.
     반드시 3.8 이어야 합니다. 3.9 이상으로 만들면 윈도우 7 에서 실행되지 않습니다.
     받는 곳: https://www.python.org/downloads/release/python-3810/
              "Windows x86-64 executable installer" 를 고르세요.
     설치할 때 "Add Python to PATH" 는 체크하지 않아도 됩니다.
   - 이미 다른 파이썬(3.11, 3.12 등)이 깔려 있어도 괜찮습니다. 같이 설치됩니다.

[ 제어기 ]  Windows 7 SP1 64비트
   - 디스크 여유 2GB 이상
   - USB 등으로 파일을 옮길 수 있어야 합니다 (인터넷 없어도 됩니다)


===============================================================
  1. 순서 요약
===============================================================

   [빌드용 PC]                          [제어기]
   ────────────                         ─────────
   2.필수패키지 다운로드.bat
        ↓  '설치본' 폴더 생성
   3.앱빌드.bat
        ↓  'ChamberInspect_WIN7' 폴더 생성
   5.모델 변환.bat  (모델 폴더 지정)
        ↓
        ├── 설치본 폴더 ─────────────->  4.제어기 설치.bat  (관리자 권한)
        ├── ChamberInspect_WIN7 폴더 ─->  원하는 위치에 복사
        └── 모델 폴더 ────────────────->  원하는 위치에 복사
                                              ↓
                                         ChamberInspect.exe 실행


===============================================================
  2. 필수패키지 다운로드   (빌드용 PC에서)
===============================================================

   "2.필수패키지 다운로드.bat" 을 더블클릭하세요.
   같은 위치에 '설치본' 폴더가 만들어지고 아래 파일들이 저장됩니다.

     Windows6.1-KB2999226-x64.msu   약 1MB    필수
        윈도우 7 에는 없는 시스템 구성요소입니다.
        이것이 없으면 앱 실행 시
        "api-ms-win-crt-runtime-l1-1-0.dll 파일이 없습니다" 오류가 납니다.

     vc_redist.x64.exe              약 26MB   필수

     Firefox Setup ...exe           약 59MB   필수
        앱 화면을 이 브라우저로 띄웁니다.
        인터넷 익스플로러로는 화면이 나오지 않습니다.

     ndp48-offline.exe              약 121MB  선택 (묻습니다. N 을 눌러 건너뛰어도 됩니다)

   ※ 받다가 실패하면 화면에 주소가 표시됩니다. 브라우저로 직접 받으셔도 됩니다.


===============================================================
  3. 앱 빌드   (빌드용 PC에서)
===============================================================

   "3.앱빌드.bat" 을 더블클릭하세요. 몇 분 걸립니다.
   끝나면 같은 위치에 'ChamberInspect_WIN7' 폴더가 생깁니다. 그게 앱입니다.

   화면에 아래처럼 나오면 정상입니다.

     Python: py -3.8
     추론 백엔드: onnxruntime 1.14.1 (.onnx)
     결과 폴더: ...\ChamberInspect_WIN7
     Windows 7 로드 가능성 검사 ... 통과

   실패하면 같은 폴더에 '빌드로그.txt' 가 남습니다. 그 파일을 보내주시면 됩니다.

   [빌드가 오래 걸릴 때]
   앱 폴더에는 파일이 5,000~9,000개 들어갑니다(파이썬 실행 환경 전체가 들어가기 때문).
   마지막 '복사 중' 단계가 몇 분 넘게 걸린다면 백신 실시간 검사가 파일을 하나씩
   열어보고 있는 것입니다. 아래처럼 하면 크게 빨라집니다.

     - 백신 설정에서 아래 두 폴더를 검사 예외로 등록
         C:\iobuild7
         (이 폴더)\ChamberInspect_WIN7
     - SSD 가 아닌 하드디스크라면 원래 시간이 걸립니다


===============================================================
  4. 제어기 설치   (제어기에서, 관리자 권한)
===============================================================

   USB 등으로 아래를 제어기에 복사합니다.

     설치본 폴더
     4.제어기 설치.bat
     ChamberInspect_WIN7 폴더
     모델 폴더 (5번에서 변환한 것)

   "4.제어기 설치.bat" 을 우클릭 - "관리자 권한으로 실행" 하세요.
   인터넷 없이 아래를 순서대로 설치합니다.

     Universal C Runtime (KB2999226)
     Visual C++ 2015-2019
     Firefox
     .NET Framework 4.8  (물어봅니다. 브라우저 모드에서는 필요 없습니다)

   끝나면 각 항목이 실제로 설치됐는지 확인해서 보여줍니다.
   "재부팅이 필요합니다" 가 나오면 재부팅한 뒤 앱을 실행하세요.


===============================================================
  5. 모델 준비   (빌드용 PC에서, 한 번만)
===============================================================

   모델 폴더에는 세 파일이 함께 있어야 합니다.

     tcn_forecast.onnx     모델 본체
     recon_meta.npz        메타 정보
     search_best.json      판정 임계값

   ※ search_best.json 이 없으면 등급(주의/경고/심각)을 계산하지 못하고
     불량이 모두 '주의' 로만 표시됩니다.

   "5.모델 변환.bat" 에 모델 폴더를 끌어다 놓으세요.
   (또는 더블클릭 후 폴더 경로를 입력)
   그 폴더 안에 바로 있는 .onnx 만 변환합니다. 버전 폴더가 여러 개면 각각 한 번씩
   끌어다 놓으세요.

   윈도우 7 에서 쓸 수 있는 추론 엔진은 조금 낮은 버전이라, 최신 형식으로 저장된
   모델을 그대로 읽지 못합니다. 이 도구가 형식 표기만 낮춰 줍니다.
   모델 내용은 바뀌지 않고, 원본은 .onnx.bak 으로 백업됩니다.
   이미 변환된 폴더에 다시 실행해도 안전합니다.

   ※ 이 변환은 빌드용 PC 에서 미리 끝내는 작업입니다.
     제어기에는 변환이 끝난 모델 폴더만 들고 가면 됩니다(src 폴더 필요 없음).


===============================================================
  6. 앱 실행
===============================================================

   ChamberInspect_WIN7 폴더 안은 이렇게 되어 있습니다.

     ChamberInspect.exe     <- 이것만 실행하시면 됩니다
     build\                 앱이 쓰는 파일들 (지우거나 옮기지 마세요)
     읽어주세요.txt
     로그\ · 데이터\        실행하면 생깁니다

   ChamberInspect.exe 를 실행합니다.
   검은 콘솔 창은 뜨지 않습니다. 잠시 후(10~30초) Firefox 가 자동으로 열리면서
   화면이 나옵니다.

   ※ 실행 직후 잠깐은 아무 반응이 없는 것처럼 보입니다. 모델을 읽는 시간입니다.
     1분이 지나도 화면이 안 나오면 아래 7번을 보세요.

   동작 기록은 화면 대신 파일에 남습니다.

     로그\app_<날짜>.log     <- [engine] 모델 로드(onnx): ... 등이 여기 적힙니다

   화면이 안 열리면 브라우저 주소창에 직접 입력하세요.

     http://127.0.0.1:8000

   처음 실행 시 설정 탭에서 아래를 지정하세요.
     - 모델 폴더
     - 검사할 데이터 폴더
     - 저장소 위치 (검사 이력을 남길 폴더)


===============================================================
  7. 문제가 생기면
===============================================================

   앱 폴더(exe 옆)에 아래 파일이 자동으로 남습니다. 그대로 보내주시면 됩니다.

     ※ 파일은 exe 가 있는 폴더에 생깁니다(build 안이 아닙니다).

     앱_시작기록.txt      어느 단계까지 진행했는지
     앱_시작오류.txt      오류 내용
     앱_크래시.txt        라이브러리 수준 오류
     로그\app_날짜.log    실행 기록

   ★ 콘솔 창이 없으므로 문제가 생기면 이 파일들이 유일한 단서입니다.
     시작에 실패하면 오류 내용을 알리는 창이 뜹니다(다른 창에 가려지지 않습니다).

   자주 나오는 것

   · "api-ms-win-crt-runtime-l1-1-0.dll 파일이 없습니다"
       -> KB2999226 이 설치되지 않았습니다. 4번을 실행하세요.

   · 창은 뜨는데 화면이 비어 있음
       -> 인터넷 익스플로러로 열린 것입니다. Firefox 를 설치하세요(4번).

   · 경고/심각 등급이 0건으로만 나옴
       -> 모델 폴더에 search_best.json 이 없습니다. 5번 설명을 확인하세요.

   · 실행해도 아무 창이 안 뜸
       -> 앱_시작오류.txt 와 로그 폴더를 확인하세요. 시작에 실패하면 알림창도 뜹니다.

   [콘솔 창을 보면서 진단하고 싶을 때]
   빌드용 PC 에서 3.앱빌드 를 실행하기 전에 아래 한 줄을 먼저 실행하면,
   콘솔이 함께 뜨는 버전이 만들어집니다.

     set IO_WES7_CONSOLE=1


===============================================================
  참고: 이 배포본에 대해
===============================================================

   윈도우 7 은 지원이 종료된 운영체제라, 여기 쓰인 구성요소들도 보안 업데이트가
   끝난 버전입니다. 폐쇄망 전용으로 사용하시기를 권장합니다.
   앱은 외부와 통신하지 않으며 127.0.0.1(자기 자신)에서만 동작합니다.

   제어기를 윈도우 10 이상으로 교체하시면 표준 배포본을 쓸 수 있습니다.
   그 경우 더 가볍고 GPU 가속도 사용할 수 있습니다.
