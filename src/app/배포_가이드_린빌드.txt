========================================================================
 IO 이상탐지 - 린(경량) 빌드 + 전제조건 설치 방식  배포 가이드
========================================================================

[구조 요약]
  - 앱(exe)       : WebView2 런타임(180MB)을 빼서 가벼움. 자주 업데이트해도 부담 적음.
  - 전제조건 설치 : 제어기(대상 PC) 당 딱 한 번만. WebView2 + VC++ 런타임 설치.
  - WebView2 를 정식 설치하면 레지스트리에 등록되어, 앱은 그냥 시스템 WebView2 를 사용.
    (기존 레지스트리 우회 패치는 자동으로 쓰이지 않으며, 그대로 둬도 무해)


------------------------------------------------------------------------
 A. 빌드 (개발/빌드 PC 에서, 한 번)
------------------------------------------------------------------------
 1) src\ 옆에  webview2_runtime  폴더를 "두지 마세요".
    (폴더가 없으면 build_webview_click.bat 이 자동으로 '린 빌드' 를 합니다.)
 2) src\app\build_webview_click.bat  더블클릭.
 3) 결과:  dist\품질검사시스템\  (런타임 미포함, 가벼움)


------------------------------------------------------------------------
 B. 전제조건 설치 패키지 준비 (인터넷 되는 우리쪽 PC 에서 한 번)
------------------------------------------------------------------------
 아래 3개 bat 을 한 폴더에 두고 시작합니다(src\app\ 에 있음. 복사해서 사용):
   - Download_Installers.bat      (설치본 자동 다운로드)
   - IO_Prerequisites_Setup.bat   (제어기에서 실행할 설치기)
   - (배포_가이드_린빌드.txt)

 [쉬운 방법] Download_Installers.bat 더블클릭
   -> 아래 2개를 같은 폴더로 자동 다운로드합니다(검증된 MS 영구 링크 사용).
        vc_redist.x64.exe                              (약 25MB)
        MicrosoftEdgeWebView2RuntimeInstallerX64.exe   (약 195MB, WebView2 오프라인 단독본)

 [수동 방법] 직접 받으려면:
   필수 1)  vc_redist.x64.exe
            https://aka.ms/vs/17/release/vc_redist.x64.exe
   필수 2)  MicrosoftEdgeWebView2RuntimeInstallerX64.exe   (Evergreen 오프라인 단독본)
            https://go.microsoft.com/fwlink/?linkid=2124701
   선택 3)  ndp48-x86-x64-allos-enu.exe   (.NET 4.7.2+ 없는 PC 만)
            https://dotnet.microsoft.com/download/dotnet-framework/net48

 => 이렇게 채운 폴더(bat + 설치본들)를 통째로 제어기에 전달하면 됩니다.
    제어기는 인터넷이 필요 없습니다(전부 오프라인 설치).


------------------------------------------------------------------------
 C. 제어기(대상 PC) 에서 (PC 당 한 번)
------------------------------------------------------------------------
 1) IO_Prerequisites_Setup.bat  ->  우클릭 -> "관리자 권한으로 실행"
      - VC++ 런타임 설치
      - WebView2 런타임 설치
      - (있으면) .NET 4.8 설치
      - 마지막에 "RESULT: Prerequisites OK" 가 나오면 성공.
 2) 앱 폴더  품질검사시스템\  를 복사해 두고,  웨이퍼품질검사.exe  실행.

 이후 앱을 업데이트할 때는 C-1(전제조건) 은 다시 안 해도 됩니다.
 앱 폴더만 새 것으로 교체하면 됩니다.


------------------------------------------------------------------------
 문제 발생 시
------------------------------------------------------------------------
 - 검은 콘솔에 pythonnet/.NET 오류 -> 전제조건 설치(C-1)를 안 했거나,
   VC++ 재배포판이 안 깔린 경우. IO_Prerequisites_Setup.bat 를 관리자로 다시 실행.
 - 빨간 박스(IE) -> WebView2 미설치. 위와 동일하게 전제조건 설치 확인.
 - 설치 자체가 막히는(관리자 불가) 환경이면, 예전처럼 webview2_runtime 폴더를
   빌드 시 함께 번들하는 '무거운 빌드' 로 되돌릴 수 있습니다(폴더만 두고 빌드).
