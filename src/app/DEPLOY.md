# 고객사 배포 가이드 — 직접 방문 없이 설치하기

> **고객사에는 소스(.py)가 나가지 않습니다.** 빌드 시 모든 .py 는 컴파일되어 exe 안에
> 들어갑니다. 제가 드린 zip(소스 포함)은 **exe 를 만드는 내부 빌드 PC 전용**이고,
> 고객이 받는 것은 **컴파일된 exe 하나**뿐입니다.

기본 빌드는 **단일 exe(onefile)** 라서 고객 전달물은 아주 단순합니다:
```
IOAnomalyConsole.exe        ← 이 파일 하나 (소스·부속 폴더 없음)
├─(실행 시 자동 생성) data\inbox\    ← 검사할 CSV 를 넣는 곳
└─(선택) models\<이름>\             ← 추가 모델 (tcn_forecast.pt + recon_search_best.json)
```
전달은 **① exe 하나를 다운로드 링크로 보내기** 만으로 끝. (원하면 아래 설치파일도 가능)

---

## 1단계 — 실행 파일 빌드 (Windows PC)
```
src\app\build_win.bat   →   dist\IOAnomalyConsole.exe   (단일 파일)
```
> - 기본이 **단일 exe(onefile)** 입니다. `dist\IOAnomalyConsole.exe` 이 파일 하나가 전달물.
> - 용량은 **CPU 버전**으로 빌드하세요(기본값). 고객 PC에 NVIDIA GPU가 없으면 GPU 버전은
>   의미 없고 용량만 2GB+로 커집니다. (build_win.bat 안 torch 줄이 `cpu` 인지 확인)
> - onefile 은 **첫 실행이 느립니다**(1회 압축 해제). 자주 켜고 끄는 환경이면 `set ONEFILE=0`
>   후 빌드해 onedir(폴더+빠른 실행)로 만들 수 있습니다.

## 2단계 (선택) — 설치파일(setup.exe)로 감싸기 (Windows PC)
단일 exe 를 그냥 링크로 보내도 되지만, **바탕화면 바로가기·설치 경험**이 필요하면:
1. **Inno Setup 6** 설치 (무료): https://jrsoftware.org/isdl.php
2. 실행:
   ```
   src\app\package_win.bat
   ```
   →  `installer_out\IOAnomalyConsole_Setup.exe` (하나의 파일)

- LZMA2 압축으로 **폴더(수천 개 파일) → 파일 1개**, 용량도 대개 **절반 수준**으로 감소.
- 전송·다운로드·설치가 모두 이 파일 하나로 끝납니다.

## 3단계 — 고객에게 전달 (직접 방문 불필요)
설치파일이 커서 이메일 첨부는 어려우니 **다운로드 링크**로 보냅니다. 택 1:

| 방법 | 용량 한도 | 비고 |
|---|---|---|
| **WeTransfer** (wetransfer.com) | ~2GB(무료) | 링크 생성 즉시, 가입 불필요 |
| **Google Drive / OneDrive** | 넉넉 | 링크 공유(권한: 링크 있는 사람) |
| **회사 파일서버 / SFTP** | 사내 정책 | 보안 요건 있으면 권장 |
| USB → 택배 | — | 인터넷 반입이 막힌 폐쇄망일 때 |

> ⚠️ 고객사 보안상 exe 다운로드가 막히면, 설치파일을 **암호 zip**으로 한 번 더 감싸
> 보내고 암호는 따로 전달하세요. (앞서 만든 방식과 동일)

## 4단계 — 고객 설치 (더블클릭)
1. `IOAnomalyConsole_Setup.exe` 실행 → 설치 마법사 (한국어)
2. **관리자 권한 불필요** — 사용자 폴더(`%LOCALAPPDATA%\IOAnomalyConsole`)에 설치
3. 바탕화면 바로가기로 실행 → 서버 기동 후 브라우저로 대시보드 자동 오픈
4. 검사할 CSV를 시작메뉴의 **"검사 폴더 열기(data\inbox)"** 에 넣고 [검사 시작]
5. 모델 교체는 **"모델 폴더 열기(models)"** 에 모델 폴더를 넣고 헤더 드롭다운에서 선택

---

## 자주 묻는 것
- **왜 이렇게 큰가요?** 파이썬·PyTorch·그래프 라이브러리를 통째로 담기 때문입니다.
  CPU 빌드 + 설치파일 압축이 현실적인 최소 크기입니다.
- **업데이트는?** 새 `setup.exe` 를 다시 보내 덮어 설치하면 됩니다.
  (검사 데이터·모델은 `data\`, `models\` 에 있어 유지됩니다. 단, 재설치 폴더가 같아야 함)
- **모델만 바꾸고 싶어요.** 프로그램은 그대로 두고 `models\<이름>\` 폴더의 웨이트만
  교체 후 드롭다운에서 선택 → **재설치 불필요**.

---

## 더 줄이고 싶다면 (선택)
- `io_console.spec` 의 `excludes` 에 안 쓰는 대형 패키지 추가(예: `scipy`, `PIL` 미사용 시).
- UPX 압축(`io_console.spec` 의 `upx=True`) — 단, torch DLL과 충돌 가능성 있어 빌드 후 반드시 실행 테스트.
- 위 두 가지는 크래시 위험이 있어, 기본은 **CPU 빌드 + 설치파일 압축**만 권장합니다.
