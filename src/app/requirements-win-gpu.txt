# Windows 빌드 PC 에 설치할 패키지 (챔버 이상검사 콘솔 .exe 빌드용)
#   python -m venv venv && venv\Scripts\activate
#   python -m pip install -U pip
#   pip install -r requirements-win.txt
#
# ★★ 전 패키지를 '서로 맞는 2024-계열'로 상·하한 고정한다. 이유:
#   상한(<)이 없으면 재빌드 때 pip 가 최신(numpy 2.x, matplotlib 3.12, 최신 hooks-contrib)을
#   깔아버리는데, 이 최신들이 PyInstaller 번들링과 어긋나 부팅에러가 난다:
#     · numpy 2.x        → "cannot load module more than once per process"
#     · numpy 1.26 + '최신' hooks-contrib(numpy 2.x 전용) → "numpy.core._multiarray_tests" 류
#     · matplotlib 3.12  → "No module named _pyi_rth_mplconfig"
#   → numpy 1.26 과 '같은 세대'의 pyinstaller/hooks-contrib 로 통일해야 일관된다.
#   지원 파이썬: 3.9 ~ 3.12 (64-bit).

# ── 추론 엔진: onnxruntime-directml (GPU 가속판) ──
#   ★ 이 파일은 '그 제어기에서 DirectML 이 동작함을 확인한 뒤'에만 쓴다.
#     DirectX 12 미지원/구형 드라이버 PC 에서는 exe 가 조용히 안 뜬다.
#     확인법: dxdiag 실행 → '시스템' 탭의 DirectX 버전이 12 인지 본다.
#     문제가 생기면 즉시 requirements-win.txt(CPU 판)로 되돌려 빌드한다.
onnxruntime-directml>=1.17.0,<1.23

pandas==2.2.2                  # ★ 정확 고정(결정적 빌드). numpy 1.26 호환.
matplotlib>=3.8,<3.10        # (exe 에선 제외됨) 리포트용. 3.10+ 는 PyInstaller 훅 미지원

#   (recon_explain._safe_auroc 는 sklearn 없으면 0.0 반환). scipy 는 설치 시 소스빌드로 자주
#   실패해 venv 를 불완전하게 만들고 "pandas dist-info 못 찾음" 같은 2차 빌드에러를 유발했음.
